# HEIA SOLA!

Six big buttons that make Spotify play a short clip of a song, for goals at the handball match.

## Put it online (GitHub Pages)
1. Create a **public** repository on github.com, e.g. `heiasola`.
2. Upload `index.html` and `icon.png` (Add file → Upload files → Commit changes).
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. After 1–2 minutes the page is live at `https://<your-username>.github.io/heiasola/`.

## Connect Spotify (once)
1. Open the page. It shows the exact redirect address to use.
2. Go to developer.spotify.com/dashboard (Premium account), then Create app → tick **Web API** → paste the redirect address → Save.
3. Copy the **Client ID** into the page and press **Log in with Spotify**.
4. The six songs are found automatically. Check each one under **Edit** and set where its clip starts.

## Before each match
- Open Spotify on the device connected to the speaker and play any song for a second.
- Open HEIA SOLA!, check the status light is green, and press **Settings → Get button 1 ready**.
- Turn on **Screen on**.
